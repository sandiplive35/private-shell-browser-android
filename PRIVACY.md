# Privacy Statement

PrivateShell Browser does not include application analytics, advertising SDKs, crash-reporting SDKs, account systems, telemetry endpoints, or an application-operated backend.

Browsing traffic still goes directly to the websites and services the user chooses to visit. Those remote services can receive network and browser information needed to communicate with the device. PrivateShell does not claim to anonymize the network connection.

The app provides a WIPE control to remove WebView cookies, web storage, cache, navigation history, form data, SSL preferences, client-certificate preferences, and HTTP-auth data under the app's control.
